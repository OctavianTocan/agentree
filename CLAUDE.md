## Teaching / explaining — always use `i-have-adhd`

Whenever you explain anything, teach how to do something, or tell the user
what to do next: load and follow the `i-have-adhd` skill first. Do this even
when the user did not invoke `/i-have-adhd`. Action first, numbered steps, one
concrete next action, no preamble, no closers.
