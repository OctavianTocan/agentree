# Examples

Sample born-digital PDFs for local experiments with `agentree`.

```bash
uv run agentree --pdf_path examples/documents/q1-fy25-earnings.pdf
```

## Documents

| File | Notes |
| --- | --- |
| `q1-fy25-earnings.pdf` | Small earnings-style PDF (good smoke test) |
| `four-lectures.pdf` | Short academic PDF |
| `attention-residuals.pdf` | Research paper |
| `earthmover.pdf` | Research paper |
| `2023-annual-report.pdf` | Longer annual report |
| `2023-annual-report-truncated.pdf` | Truncated annual report |
| `Regulation Best Interest_proposed rule.pdf` | Regulatory PDF |
| `Regulation Best Interest_Interpretive release.pdf` | Regulatory PDF |
| `PRML.pdf` | Large textbook PDF (~17MB); expect slower indexing |

These files are for development and demos. Redistribute only if you have the
right to do so for each document. Prefer the smaller PDFs when filing issues.
